🚀 Generador de Prompts Efectivo

Crea instrucciones precisas para obtener los mejores resultados con IA

Un prompt efectivo es la clave para obtener respuestas precisas, relevantes y útiles de cualquier modelo de inteligencia artificial. La estructura correcta de un prompt puede marcar la diferencia entre una respuesta genérica y una solución perfectamente adaptada a tus necesidades.

Este sitio web ha sido desarrollado por el Dr. Raúl Eduardo Rodríguez Ibáñez. Para facilitar la creación de Una Página web sobre temas específicos. La interfaz del sitio ha sido mejorada con Claude.ai

🧠

1. Contexto

Proporciona información de fondo que ayude a la IA a entender la situación completa. Define el escenario, el propósito y cualquier información relevante que enmarque tu solicitud.

Ejemplo:
"Escenario web para presentación de resultados de proyectos."
🎭

2. Rol o Perspectiva

Define el papel que quieres que asuma la IA. Esto influye en el tono, el estilo y el enfoque de la respuesta.

Ejemplo:
"Actúa como desarrollador de sitios web en publicación de dashboard interactivo "
🌐

3. Tarea Específica

Describe claramente qué quieres que haga la IA. Sé específico y directo sobre la acción esperada.

Ejemplo:

"Crea un sitio web en html con las siguientes secciones: Sección: Presentación del sitio web: 'Este recurso nos muestra como utilizar un prompt efectivo, fue creado por (Coloque sus nombres y apellidos) .

Este recurso fue creado bajo la metodología QCHE del Dr. Raúl E.Rodríguez Ibáñez (¿Qué voy a hacer? ¿Cómo lo voy a hacer? Hacer y Evaluar). El siguiente sitio web se creará bajo licenciamiento Creative Commons. Con los archivos anexos Resultados.xlxs y rúbrica.xlxs crea Sección: 1.1 Análisis de resultados ¿Cómo lo voy a hacer? Ejecute el siguiente prompt (coloque aquí el prompt del Análisis ) Posteriormente en la sección 1.2 Diseño de dashboad, ejecute el siguiente prompt (coloque aquí el prompt del Diseño ). En la sección 1.3 Hacer el dashboard. Ejecute el siguiente prompt (coloque aquí el prompt del hacer). En la sección 1.4 Evaluar el dashboard, ejecute el siguiente prompt (coloque aquí el prompt del evaluar ). En la sección 1.5 Conclusiones y recomendaciones ejecute el siguiente prompt (coloque aquí el prompt de las conclusiones y recomendaciones )). Represente en un árbol jerárquico los contenidos anteriores creados desde 1.1 a 1.5 .Diseñar al lado izquierdo de la página un menú flotante con los ítems 1.1 hasta 1.5 que permita al usuario conectar al desarrollo de cada una de las temáticas viéndolas al lado derecho. Incluir en cada ítem una imagen horizontal decorativa generados con IAG de acuerdo al tema.

 

💡

4. Datos de Entrada

Proporciona información concreta, ejemplos, datos o parámetros que la IA deba considerar para generar la respuesta.

Ejemplo:
"Público en general, personas entre 16 y 85 años, profesores, estudiantes, investigadores y empresarios."
🎯

5. Formato de Salida

Especifica cómo quieres recibir la información: lista, tabla, párrafo, código, JSON, HTML, etc.

Ejemplo:
"Formato de salida en html5 compatible con navegadores y compatible con dispositivos móviles, use plantilla web RESPONSIVE: Breakpoints: mobile, tablet, desktop, adaptaciones específicas. ACCESIBILIDAD: WCAG 2.1 AA compliance, navegación por teclado, arial labels."
⚙️

6. Restricciones o Limitaciones

Define límites como longitud, tono, vocabulario, aspectos a evitar o consideraciones especiales.

Ejemplo:
"Máximo 5000 palabras, tono casual pero profesional, evita jerga técnica compleja."
